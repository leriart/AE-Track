# 5.14.8

La IA del chat ahora conoce el **manual de Rondo** y un **contexto de
flota mucho mas rico**, para que pueda ayudar a los usuarios tanto con
dudas de uso como con datos concretos. Tambien se actualizan la ayuda
rapida y el manual.

## 1. El chat conoce el manual

Nueva constante `RONDO_DOC`: un resumen estructurado del manual de
Rondo que se inyecta en el system prompt del chat. Cubre:

- Que es Rondo y como funciona (userscript sobre AE-Track/Wialon).
- El panel y **cada pestana** (Dashboard, Unidades, Avisos, Rutas,
  Zonas, Caravana, Chat IA).
- **Todas las reglas** de alerta con sus umbrales por defecto.
- **Todas las secciones de Ajustes** (General, Reglas, Avisos, Visual,
  Ventanas, Rutas, IA, Avanzado).
- Atajos de teclado.
- El flujo de la IA (veredicto, lote, patrones, chat).

El system prompt le indica a la IA que tiene **dos fuentes**:
1. **El manual** (para "como hago X" / "que hace Y").
2. **El contexto de flota** adjunto (para datos concretos).

Antes, la IA solo respondia a datos; ahora tambien explica el sistema.
Ejemplos:

- "Como activo la regla de destino?" -> pasos concretos.
- "Que hace el boton Analizar lote?" -> descripcion.
- "Para que sirve la zona de riesgo?" -> explicacion + como cargarla.

## 2. Contexto de flota enriquecido (acceso a datos de la plataforma)

`chatContextoFlota()` ahora expone un **snapshot completo** de los
datos de la plataforma que Rondo ya tiene en memoria. Campos:

```json
{
  "geocercasCargadas": true,
  "unidadesEnAlcance": 28, "enLinea": 25, "sinSenal": 3,
  "unidadesFueraDeGeocerca": 19,
  "ecosFueraDeGeocerca": ["4381", "2204", ...],
  "offlineFueraDeGeocerca": ["4381"],
  "unidades": [
    { "eco": "4381", "placa": "ABC123", "estado": "offline",
      "zona": null, "edadMin": 12, "vel": 0 },
    { "eco": "2204", "placa": "XYZ789", "estado": "online",
      "zona": "CEDIS Norte", "edadMin": 1, "vel": 45 }
  ],
  "geocercas": [
    { "nombre": "CEDIS Norte", "unidadesDentro": ["2204"] }
  ],
  "zonasDeRiesgo": { "total": 120, "alto": 30, "medio": 60, "bajo": 30 },
  "alertasHoy": 17, "porSeveridad": { "critico": 2, "alto": 4, ... },
  "ultimosAvisos": [
    { "ts": "14:31", "sev": "critico", "regla": "offline", "eco": "4381",
      "titulo": "SIN SENAL · 4381", "detalle": "fuera de geocercas · ..." }
  ],
  "desconexionesHoy": [
    { "ts": "14:31", "eco": "4381", "regla": "offline",
      "detalle": "fuera de geocercas · ..." }
  ],
  "rutasActivas": 2
}
```

Novedades respecto a 5.14.7:

- **`zona` por unidad** con `null` = fuera de toda geocerca (y
  `geocercasCargadas: false` cuando no se pudieron evaluar, para que
  la IA no mienta).
- **`geocercas[]`** con las unidades dentro de cada una.
- **`zonasDeRiesgo`**: resumen por nivel.
- **`ultimosAvisos`** ahora incluye el **detalle** (que trae la zona o
  "fuera de geocercas"), no solo el titulo.
- **`desconexionesHoy[]`**: los avisos de sin senal/desconexion de hoy
  con su detalle, para correlacionar la zona con el evento.
- **`rutasActivas`** y **`ecosFueraDeGeocerca`**.

Con esto, la pregunta del reporte *"Que unidades que se encuentren
fuera de geocerca se han desconectado?"* se responde directamente con
`offlineFueraDeGeocerca`, y la IA puede explicar por que lo sabe.

El system prompt (`CHAT_SYS`) documenta **cada campo** del contexto y
advierte que si `geocercasCargadas` es false, no debe afirmar que una
unidad esta "fuera de geocerca". Los avisos recientes suben a 10.

## 3. Ayuda rapida actualizada

El dialogo de ayuda rapida (`Ajustes > ?`) ahora incluye:

- La pestana **Chat IA** en "Que hace cada pestana".
- Una seccion **"Chat con la IA"** con ejemplos de consultas (datos y
  de uso) y la explicacion del selector **Toda la flota**.
- El atajo **Alt + 7**.

## 4. MANUAL.md actualizado

- "Las seis pestanas" -> **"Las siete pestanas"** con la nueva entrada
  de Chat IA.
- Nueva seccion **"## Chat con la IA"**: para que sirve, ejemplos,
  controles, persistencia y notas (limite diario, no inventa datos).
- Dos reglas nuevas en la tabla: **Aproximacion a zona de riesgo** y
  **Detenida en geocerca**, con sus subsecciones de detalle.
- Seccion de Ajustes: anadida la pestana **IA**.
- Tabla de atajos: anadido **Alt + 7**.

## 5. Atajo Alt + 7

Abre la pestana de Chat IA. Solo funciona si la IA esta habilitada con
API key (si no, se ignora).

## Compatibilidad

- Cero cambios al flujo de reglas automaticas.
- El manual en el system prompt anade ~1200 tokens por mensaje; si tu
  proveedor tiene contexto corto, los modelos recomendados (DeepSeek,
  Moonshot, NVIDIA) lo manejan sin problema.
- El chat sigue respetando el limite diario de llamadas.
