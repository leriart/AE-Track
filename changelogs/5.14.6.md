# 5.14.6

Dos cambios visuales + una feature nueva:

1. **Fix: ya no aparecen dos botones "Cerrar"** en los dialogos
   informativos (era un bug cosmetico desde 5.14.3).
2. **Nueva tab "Chat IA"** para consultas libres con la IA, con el
   contexto actual de la flota inyectado en cada turno.

## 1. Fix: dialogos sin boton duplicado

Antes, los dialogos informativos (errores de IA, resultados de
analisis en lote, "no se encontraron patrones") tenian **dos botones
identicos "Cerrar"** (uno como cancel, otro como OK). El operador
veia "Cancelar" o "Cerrar" dos veces y se preguntaba cual pulsar.

**Solucion**: en `abrirDialogo`, si el texto del boton cancel y el
del OK coinciden (tras aplicar defaults), se oculta el cancel y solo
se muestra el OK. **No se toca ninguna llamada existente** — el fix
se aplica automaticamente a todos los dialogos que tenian este
problema.

Los dialogos que siguen mostrando ambos botones son los que tienen
textos distintos (ej. "Cancelar" / "Aplicar", "Cancelar" / "Aceptar").

## 2. Nueva tab "Chat IA"

Pestana de chat conversacional con la IA. Solo aparece si la IA esta
habilitada y con API key configurada (si la desactivas, la tab se
oculta y si estaba abierta salta al Dashboard).

### Como se ve

```
+--------------------------------------------------+
| [Robot] Chat IA · DeepSeek · deepseek-chat  [Limpiar] |
+--------------------------------------------------+
|                                          |
|  ¿Cuantas unidades tengo sin senal?     |
|                            (yo, derecha) |
|                                          |
| (IA)  Tienes 3 unidades sin senal:        |
|       Eco 4381 (hace 12 min),             |
|       Eco 2204 (hace 8 min),              |
|       Eco 9912 (hace 4 min).              |
|                                          |
+--------------------------------------------------+
| [Escribe tu consulta a la IA...] [Enviar ➤]  |
+--------------------------------------------------+
```

- Burbujas estilo chat: usuario a la derecha (color acento), IA a
  la izquierda (gris suave). Mensajes de error en rojo.
- Indicador "typing" (3 puntos animados) mientras la IA piensa.
- Auto-scroll al fondo al recibir respuestas.
- Boton "Limpiar" arriba a la derecha (con confirmacion).
- Textarea con autoresize (Enter envia, Shift+Enter = nueva linea).
- Conversacion persiste en `sessionStorage` (se borra al cerrar
  la pestana, max 50 mensajes para no inflar LS).

### Contexto automatico

Cada turno del system prompt incluye un resumen del estado actual:

```json
{
  "fecha": "2026-09-24 14:32",
  "unidadesVigiladas": 28,
  "enLinea": 25, "sinSenal": 3,
  "alertasHoy": 17,
  "porSeveridad": { "critico": 2, "alto": 4, "medio": 8, "bajo": 3 },
  "ultimosAvisos": [
    { "ts": "14:31", "sev": "critico", "regla": "riesgoSinSenal",
      "eco": "4381", "titulo": "PERDIO SENAL EN ZONA DE RIESGO · 4381" },
    ...
  ]
}
```

El system prompt le dice a la IA que use SOLO esos datos, no invente
numeros ni direcciones, y sea breve (2-5 lineas salvo detalle).

### Ejemplos de uso

- "¿Cuantas unidades tengo sin senal ahora?"
- "¿Que unidades llevan mas tiempo detenidas?"
- "¿Cual es la alerta critica mas urgente de revisar?"
- "Explicame por que la regla offline disparo en 4381"
- "Que unidad deberia revisar primero y por que?"

### Configuracion

Ninguna nueva. Reusa el proveedor/modelo/temperature/maxTokens
configurados en Ajustes > IA. El contador diario (`iaLimiteDiario`)
tambien aplica: si llegas al tope, el chat devuelve error amable.

### Arquitectura

- `CHAT` (en sessionStorage bajo `rondo.api.chat`): `{ mensajes: [...] }`
- Mensajes: `{ role: 'user'|'ia'|'error'|'system', text, ts, meta? }`
- `cargarChat()` / `guardarChat()` / `limpiarChat()`
- `chatContextoFlota()`: snapshot fresco del estado para el system prompt
- `aiChatLlamar(mensajes)`: hace POST al endpoint con todo el historial
  + system prompt con contexto (slice de ultimos 20 mensajes para
  no agotar tokens)
- `chatEnviar()`: handler del boton + Enter. Pinta estado "typing",
  llama a la IA, push del mensaje al log, scroll al fondo.
- `pintarChat()`: render del log con empty state + mensajes + typing
- `paintTabsChat()`: muestra/oculta la tab segun `iaHabilitada && iaApiKey`

## Compatibilidad

- Cero cambios al flujo de reglas automaticas, caravanas, etc.
- La tab Chat se oculta si IA no esta configurada: el comportamiento
  para usuarios que no usan IA es identico a antes.
- Si el usuario borra la API key mientras tiene la tab abierta, salta
  al Dashboard automaticamente.
