# 4.9.0

El color de acento se aplica de forma consistente a toda la interfaz.

## Cambiado

- Los botones de accion principal que tenian el color de acento
  (`#850D22`) aplicado de forma directa ahora usan la variable CSS
  `var(--hjp-accent)`, de modo que si el usuario cambia el acento en Ajustes
  se actualizan tambien.
- Las sombras (`box-shadow`) de los elementos acentuados usan
  `rgba(var(--hjp-accent-rgb), ...)` en lugar de un valor RGBA fijo, por lo
  que el brillo refleja el color elegido.
- El valor por defecto del control de acento en Ajustes es ahora `#850D22`
  (antes `#1565c0`).

## Notas

- Los botones de acciones destructivas (Borrar, Vaciar lista) siguen en rojo
  de peligro de forma intencionada, para diferenciarlos del acento.
- El boton de actualizacion disponible sigue siendo verde y el boton armado
  para confirmar cierre, rojo, como indicadores semanticos.
