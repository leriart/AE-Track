# 5.0.0

Rebrand completo: el proyecto pasa a llamarse **Rondo** y el archivo del
userscript a `rondo.user.js`. Es una continuacion natural del proyecto,
con una nueva identidad y los algoritmos ampliados de las versiones 4.x.

## Cambios principales

- El proyecto se llama **AE-TrackRondo**; el script se llama **Rondo**.
- Archivo del userscript: `HJP-Wialon.user.js` -> `rondo.user.js`.
- `@name` del userscript: `Rondo`.
- Cabecera, panel, bienvenida, titulo del informe y documentacion actualizados.
- Variables CSS, IDs y clases del DOM migrados de `#hjp-*` / `.hjp-*` a
  `#rondo-*` / `.rondo-*` para mantener coherencia bajo el nuevo nombre.
- Version bumped a 5.0.0 por ser una nueva identidad de producto (los
  gestores de userscripts la tratan como un script distinto, lo que permite
  instalar Rondo junto al antiguo HJP Wialon si alguien conserva la version
  previa).

## Compatibilidad y migracion de datos

Rondo lee y escribe en `localStorage` con el prefijo `rondo.api.*`. La
primera vez que se ejecuta, si detecta la version anterior instalada,
**copia** automaticamente las claves `hjp.api.*` y `hjp.api.s.*` al nuevo
espacio `rondo.api.*` / `rondo.api.s.*`. La copia (no el movimiento) preserva
los datos de ambas instalaciones, de modo que si conservas el script antiguo
"HJP Wialon" sigue funcionando con su propia configuracion. La marca
`rondo.api.migrated` impide repetir el trabajo.

Nada cambia para una instalacion nueva: empieza con la configuracion por
defecto.
