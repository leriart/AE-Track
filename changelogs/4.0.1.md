# 4.0.1

Version inicial publicada en GitHub.

## Anadido

- Userscript HJP Wialon con la API nativa de Wialon: reglas de negocio,
  notificaciones por toast, voz y pitido, automatizacion de ventanas y panel con
  Dashboard, Unidades, Bitacora y Geocercas.
- Metadatos de usuarioscript para Tampermonkey: `@updateURL` y `@downloadURL`
  apuntando a la rama `main` para permitir la actualizacion automatica.
- README con instalacion por navegador e instalacion automatica.

## Cambiado

- Renombrado del archivo a `HJP-Wialon.user.js` para que el gestor de
  userscripts detecte la instalacion desde GitHub Raw.
