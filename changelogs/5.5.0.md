# 5.5.0

Expansion mayor de la UI de la pestana **Riesgo**: graficos, filtros
visuales, interactividad, exportacion y empty states con onboarding.
Se mantienen los algoritmos puros anteriores y se anaden 9 nuevos
con tests dedicados.

## Cambios principales

### Hero visual (mas rico)

- **Dona SVG** con segmentos por nivel (alto/medio/bajo) y total en el
  centro. Reemplaza la barra lineal anterior. La dona usa
  `stroke-dasharray`/`stroke-dashoffset` calculados a partir de
  `donutSegmentos` y `donutDashArray`.
- **Histograma de scores** en una caja separada: 5 buckets
  (`0-19`, `20-39`, `40-59`, `60-79`, `80-100`) con barras verticales
  coloreadas por nivel, alto basado en el bucket con mas elementos.
  Tooltip nativo por barra con la cantidad exacta.
- **KPIs clickeables**: hacer clic en Total / Alto / Medio / Bajo
  aplica el filtro de nivel correspondiente. Un segundo clic en el
  mismo KPI lo desactiva (vuelve a "todas"). El KPI activo se
  resalta con un anillo del color del nivel.

### Pestana (sidebar) mejorada

- **Contador en la pestana Riesgo**: muestra el total de zonas
  cargadas al lado del icono (como las demas pestanas).
- **Indicador de regla activa**: punto verde pulsante visible en la
  pestana Riesgo cuando `cfg.reglas.riesgoSinSenal` esta activo y
  hay zonas cargadas. El borde inferior de la pestana tambien se
  ilumina en verde.

### Filtros y vista

- **Slider para "Score min."** (rango 0-100) en lugar de un input
  numerico. Valor mostrado en vivo al lado del slider, actualizado
  con `input` events.
- **Sticky filters**: la seccion de filtros se queda fija al hacer
  scroll (con fondo solido para que el contenido no se vea detras).
- **Boton "Expandir / colapsar todo"** junto a los demas controles
  de filtros.
- **Animacion suave** (transition de 200 ms) al cambiar los chips de
  nivel para dar feedback visual.

### Lista y cards

- **Cards con animacion de entrada** (`rondoFadeUp`) para que
  aparezcan escalonadas al repintar.
- **Boton "Copiar" por card** (icono clipboard) que aparece en
  hover y copia el detalle completo de la zona al portapapeles.
- **Tooltip nativo enriquecido** en cada card con todos los
  detalles: estado, municipio, id, score, buffer, coordenadas
  (4 decimales), fuente y delitos.
- **Acciones en hover**: aparecen con `opacity: 0 -> 1` al pasar
  el raton sobre la card.
- **Indicador en la card del nivel del KPI filtrado**: si el
  usuario hace clic en el KPI "Alto", todas las cards con score alto
  se benefician del estado visual consistente.

### Export / copia

- **Barra de exportacion** debajo de los filtros con tres botones:
  - **CSV**: `rondo_riesgo_YYYY-MM-DD.csv` con header
    `estado,municipio,score,radio_m,lat,lon,fuente,id,delitos`.
    Delitos serializados como `delito:conteo;delito:conteo`.
  - **GeoJSON**: `rondo_riesgo_YYYY-MM-DD.geojson` con
    `FeatureCollection` de puntos (lon, lat) y `properties` con
    todos los campos relevantes.
  - **Copiar**: envia el subset visible al portapapeles via
    Clipboard API (con fallback a `textarea + execCommand`).
- **Boton "Exportar" grande**: abre menu contextual con las mismas
  3 opciones.
- **Aviso (toast)**: `adviceOk`/`adviceErr` para confirmar el
  exito o el fallo.
- **Operan sobre el subset visible**: respetan los filtros actuales
  (texto + nivel + orden). Si no hay items visibles, muestran
  advertencia.

### Drag-and-drop

- **Drop overlay** sobre las dos toolbars (URL y archivo): cuando
  arrastras un archivo sobre la pestana aparece un overlay con
  borde discontinuo y el texto "Suelta el archivo aqui".
- Acepta cualquier archivo CSV/JSON/TSV/TXT.
- Dispara el mismo flujo que el input file tradicional.

### Empty states con onboarding

- **Cuando no hay zonas cargadas**: empty state con 3 pasos visuales
  numerados (Pega URL -> Recarga -> Activa la regla) y un boton
  directo a Ajustes.
- **Cuando hay zonas pero el filtro no devuelve nada**: empty state
  indicando el conteo ("Visibles: 0 de N") con un boton para limpiar
  filtros.
- **Tiempo relativo** en el status banner: "hace 5 min" en lugar de
  la fecha completa cuando es reciente; la fecha absoluta se sigue
  mostrando en el detalle.

### Cambios menores

- **Estado "ultima carga"** muestra "hace X min/h/d" ademas de la
  fecha completa, calculada con `tiempoRelativo(ts)`.
- **Animacion `rondoFadeUp`** aplicada a cada card al repintar.

## Algoritmos nuevos (funciones puras)

Todas viven en el mismo bloque "Algoritmos UI de la pestana Riesgo".
Son independientes del DOM y se cubren con tests.

| Funcion | Que hace |
| --- | --- |
| `donutSegmentos(alto, medio, bajo, size, grosor)` | Calcula parametros del arco SVG (fracciones, longitudes, circunferencia). |
| `donutDashArray(seg, circ)` | Calcula `stroke-dasharray`/`stroke-dashoffset` para 3 segmentos sin solapamientos. |
| `histogramaScores(items, buckets)` | Cuenta items por buckets de score (5 por defecto: 0-20, 20-40, ...). |
| `tiempoRelativo(ts)` | "hace X s/min/h/d" o "recien" para el futuro. |
| `riesgoParaCSV(items)` | Filas para CSV (header + datos). |
| `riesgoParaGeoJSON(items)` | FeatureCollection GeoJSON con Point geometries. |
| `riesgoParaClipboard(items)` | Texto plano para copiar al portapapeles. |
| `riesgoDetalleHTML(z)` | HTML compacto con todos los campos para tooltips. |

## Estado y bindigs nuevos

- `riesgoKpiActivo` (estado efimero, no se persiste) controla que
  KPI del hero esta activo visualmente (basado en `APP.riesgoNivel`).
- Drag-and-drop con clase `.drag-over` sobre las toolbars.
- Slider `rondo-riesgo-min` con evento `input` para repintar en vivo.
- Click delegation extendida para: botones de copiar por card,
  boton KPI, boton empty-state "Abrir Ajustes", boton expandir todo.

## Detalles tecnicos

- **Dona SVG**: usa `<circle>` con `transform: rotate(-90deg)` y
  `stroke-dasharray` para cada segmento. Calculado por
  `donutSegmentos` + `donutDashArray`, dibujado en `renderRiesgoDona`.
- **Sticky filters**: `position: sticky; top: 0` con
  `background: var(--rondo-bg-soft)` para que el contenido no se
  filtre por debajo.
- **Drop overlay**: se muestra con `opacity: 0 -> 1` al detectar
  `dragenter`/`dragover`; se quita con `dragleave`/`drop`. Crea un
  `DataTransfer` y lo asigna al input file real para reutilizar el
  handler existente.
- **Slider**: usa `appearance: none` y custom track con
  `linear-gradient` y thumb circular del color de acento. El valor
  se actualiza en cada `input` event (no espera al `change`) para
  feedback instantaneo.
- **Copiar al portapapeles**: usa `navigator.clipboard.writeText`
  si esta disponible, con fallback a `textarea + execCommand`.
  Captura excepciones y avisa via toast.

## Compatibilidad

- Cero cambios en la regla `reglaRiesgoSinSenal`, en
  `puntoEnZonaDeRiesgo` o en el parser de CSV/JSON.
- Cero cambios en la configuracion persistida
  (`APP.config.riesgoUrl`, `riesgoFormato`, `riesgoMinScore`,
  `riesgoRadioMul`).
- El score minimo sigue siendo un `number` en localStorage; el
  slider lo escribe igual que hacia el input anterior.
- Los usuarios con un dataset previo ven los KPIs y la dona con
  los valores correctos al primer repintado.

## Tests

La suite `tests/riesgo.test.js` pasa de **84** a **131** checks:

- `donutSegmentos`: casos vacio, mixto, validacion de radio y
  circunferencia, suma de fracciones, longitudes proporcionales.
- `donutDashArray`: longitud total igual a circunferencia, offsets
  consistentes entre segmentos.
- `histogramaScores`: 5 buckets por defecto, total = items,
  max = bucket mayor, asignacion correcta a buckets, casos vacio.
- `tiempoRelativo`: "hace 0 s", futuro -> "recien", escalas
  (segundos, minutos, horas, dias), null -> "".
- `riesgoParaCSV`: header correcto, score/radio numericos,
  delitos serializados, vacio -> solo header.
- `riesgoParaGeoJSON`: type FeatureCollection, geometria Point,
  coords `[lon, lat]`, properties correctas.
- `riesgoParaClipboard`: cabecera, cantidad, una linea por item,
  incluye score y estado, vacio -> "".
- `riesgoDetalleHTML`: incluye estado, score, buffer, coordenadas,
  vacio -> "".

Total del proyecto: **8 suites, 131+ tests** en `tests/riesgo.test.js`
+ tests existentes en las otras 7 suites.
