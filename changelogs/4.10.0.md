# 4.10.0

Lista de unidades por pestaña (aislamiento entre pestanas del navegador).

## Anadido

- La lista vigilada (economico y destino), la seleccion de unidades, las
  unidades silenciadas, los limites de velocidad, el historial de avisos y la
  cache de geocodificacion se guardan ahora **por pestaña** usando
  `sessionStorage`, en lugar de compartirse entre todas las pestanas del mismo
  origen.
- De este modo, dos pestanas del mismo navegador (por ejemplo dos instancias o
  dos vistas con datos distintos) muestran y conservan su propia lista de
  unidades, sin pisarse entre si.
- Los datos persisten al recargar la pestaña y se migran automaticamente desde
  el almacenamiento global anterior (`localStorage`) la primera vez que se abre
  cada pestaña, para no perder la lista existente.

## Notas

- La configuracion general (tema, acento, reglas, panel, etc.) sigue siendo
  global y compartida entre pestanas.
- El almacenamiento por pestaña dura mientras la pestaña esta abierta (incluye
  recargas). Si cierras la pestaña, su lista se descarta; usa **Exportar
  configuracion** si quieres conservarla.
