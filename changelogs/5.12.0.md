# 5.12.0

Test de voz integrado e **IA de razonamiento** que evalua cada aviso con
contexto real (geocercas, POIs cercanos via OpenStreetMap Overpass,
historial reciente de la unidad) y devuelve un veredicto estructurado.

## Test de voz

Hasta ahora cambiar el motor / idioma / voz era a ciegas: solo se podia
escuchar el resultado cuando saltase una alerta real. Ahora hay un boton
**Probar voz** en *Ajustes &rsaquo; Avisos* que reproduce una frase con la
configuracion vigente (motor, idioma, voz y volumen actuales), un boton
**Detener** para cortarlo en seco y un campo de texto para editar la frase
de prueba (por defecto: *"Aviso de prueba de Rondo. Unidad 1234 sin senal
hace cinco minutos."*).

- `web` (Web Speech API del navegador): respeta la voz y velocidad elegidas.
- `online` (StreamElements / Polly): respeta la voz de la lista.
- `google` (Google Translate TTS): respeta el idioma.

La frase se guarda en `localStorage` (`APP.config.vozTest`) al pulsar
Guardar en la pestana de Avisos.

## IA de razonamiento

Nueva pestana **IA** en Configuracion con tres proveedores compatibles con
OpenAI Chat Completions que dan API key gratis sin tarjeta de credito:

| Proveedor | Endpoint | Modelo por defecto | Free tier |
| --- | --- | --- | --- |
| **DeepSeek** | `api.deepseek.com` | `deepseek-chat` | si, generoso |
| **NVIDIA NIM** | `integrate.api.nvidia.com` | `meta/llama-3.1-70b-instruct` | si, con creditos gratuitos |
| **Moonshot Kimi** | `api.moonshot.ai` | `kimi-k2.7-code-highspeed` | si, limitado |

El usuario mete su API key (se guarda en `localStorage` con prefijo
`rondo.api.*` y nunca sale del navegador salvo al endpoint del proveedor).

### Como se usa

1. *Ajustes &rsaquo; IA*: marcar **Habilitar IA**, elegir proveedor, pegar
   API key, opcionalmente sobreescribir el modelo. Pulsar **Probar
   conexion** para verificar que responde.
2. En la pestana **Avisos**, cada tarjeta muestra un boton **IA** cuando
   la IA esta habilitada y configurada. Al pulsarlo:
   - Rondo junta contexto de la unidad (eco, placa, estado, ultima
     posicion, geocerca actual si esta dentro, ultimas 5 alertas de la
     misma unidad).
   - Llama a **Overpass** para pedir POIs peligrosos a `R m` alrededor de
     la ultima posicion (talleres, deshuesaderos, estacionamientos,
     bares, parques, etc.).
   - Envia el contexto al proveedor elegido con un system prompt que
     instruye al modelo a razonar como analista de seguridad y devolver
     un veredicto estructurado en JSON.
   - Pinta el veredicto en la propia tarjeta del aviso con la confianza,
     el resumen, la evidencia y una recomendacion accionable.

### Veredicto (JSON pedido al modelo)

```json
{
  "veredicto": "falso_positivo" | "normal" | "sospechoso" | "critico",
  "confianza": 0.0 - 1.0,
  "resumen": "1-2 frases en espanol",
  "evidencia": ["..."],
  "recomendacion": "accion concreta"
}
```

La UI pinta el veredicto con un color por nivel (verde / azul / ambar /
rojo) y muestra la confianza y el nombre del proveedor usado.

### Seguridad y privacidad

- La API key **solo se envia al endpoint del proveedor** (DeepSeek,
  NVIDIA o Moonshot). Rondo no la loggea, ni la manda a ningun sitio mas.
- El campo aparece enmascarado (`********`) en la UI al abrir
  configuracion; si no la tocas, se conserva.
- Boton **Borrar API key** en la pestana IA limpia el valor al instante.
- La IA **no toca el flujo automatico**: las reglas siguen evaluandose
  igual. El boton IA es **manual** y se lanza cuando tu quieras.
- Timeouts: 25 s por defecto (configurable 5-120 s), 8 s para Overpass.
