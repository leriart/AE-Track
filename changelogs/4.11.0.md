# 4.11.0

Orden personalizable de las ventanas de unidades.

## Anadido

- La lista de unidades define ahora el **orden** con el que se abren y se
  acomodan las ventanas de los vehiculos.
- Botones de orden en la lista de unidades:
  - **Pegado**: el orden en que se pegaron o agregaron.
  - **Numero**: por economico de menor a mayor.
  - **Numero inverso**: de mayor a menor.
  - **A-Z**: orden alfabetico.
  - **Invertir**: invierte el orden actual.
- **Arrastrar y soltar**: cada fila tiene un asa (⠿) para arrastrarla y
  cambiar el orden manualmente. El numero a la izquierda muestra la posicion.
- El orden se guarda por pestaña y se aplica tanto al abrir las ventanas
  (Automatizar Unidades) como al organizarlas en pantalla.

## Cambiado

- `organizeWindows` coloca las ventanas segun la lista en vez de segun el
  orden del DOM.
- Al importar una configuracion, el orden se reconstruye a partir de la lista.
