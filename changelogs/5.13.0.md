# 5.13.0

**Nuevo proveedor de voz, gratis y sin API key**: [ttsmp3.com](https://ttsmp3.com).
Es el motor **Online** principal ahora; StreamElements pasa a ser la
alternativa y Google el ultimo recurso.

## Por que

StreamElements se satura con facilidad (rate limit: alterna 200 y 401) y, al
fallar, la voz caia a Google (una sola). Por eso parecia que "todas las voces
suenan igual". Se buscaron alternativas **gratuitas y sin registrar ninguna
API key** y ttsmp3.com es la mejor: en pruebas aguanto **10 peticiones
seguidas** sin un solo fallo.

| Proveedor | Key | Voces es | Fiabilidad |
| --- | --- | --- | --- |
| **ttsmp3.com** (nuevo) | No | 7 (Polly) | Alta |
| StreamElements | No | 6 (Polly) | Baja (se satura) |
| Google Translate TTS | No | 1 | Alta |
| MiniMax | Si (free tier) | 47 | Alta — **no** se usa: requiere key |

> El usuario pidio explicitamente "gratis y sin API". Por eso **no** se
> integra MiniMax ni otros que piden key, aunque tengan free tier. Todo lo
> que usa Rondo para la voz es sin key.

## Como funciona

`ttsmp3.com` no devuelve el audio directo: se le hace un **POST** al
formulario publico y responde un JSON con la **URL del MP3**:

```
POST https://ttsmp3.com/makemp3_new.php
     msg=<texto>&lang=<voz>&source=ttsmp3
 -> { "Error":0, "URL":"https://ttsmp3.com/created_mp3/<hash>.mp3" }
```

Esa URL se descarga por `GM_xmlhttpRequest` (salta CORS y CSP) y se
reproduce por Web Audio, con la cache habitual (la misma frase+voz devuelve
el mismo hash, asi que suena al instante la segunda vez).
